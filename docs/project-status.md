## 测试边界

原版 305 项与当前 255 项是不同套件。供应商专用协议 helper 的旧测试已另存私有审计目录；当前测试覆盖通用适配器契约和工作流行为，不验证任何商业供应商的真实实现。草稿精确时长查询、片段容错和水印关键帧由部署者适配器实现。

默认没有渠道。文本可配置通用 chat-completions 协议，图像、音频、视频和草稿服务需要部署者提供相应服务器适配器，并非填入任意 API Key 就能使用全部生成。
