# Workflow Studio

**一个面向 AI 视频内容创作的工作流网站源码，将选题、文案 / 剧本、分镜、配音、图片和视频任务组织在同一个网页工作台中。** 适合想学习 AI 创作平台实现方式，或在此基础上接入自己的模型服务、改造创作工具的开发者。

## 这个项目能做什么

仓库包含前端界面、后端 API、后台任务 Worker，以及相关工作流逻辑和内置提示词。主要模块包括：

| 模块 | 用途 |
| --- | --- |
| 选题与文案 / 剧本 | 从选题或已有内容开始创作，组织文案生成、剧本优化、历史版本及内容检查流程 |
| 分镜与视频提示词 | 组织传统分镜和 AI 导演分镜两种模式，为后续图片、视频任务准备镜头描述与提示词 |
| 图片、视频与音频 | 提供对应的创作界面和任务调用机制，管理生成进度与结果 |
| 素材管理 | 管理创作中复用的角色、场景等素材，以及视频分析和写作风格分析任务 |
| 工作流任务 | 保存创作项目和各阶段结果，通过后台队列处理耗时任务 |
| 素材与草稿导出 | 提供素材下载、打包及通过适配器对接草稿导出的流程 |
| 账号与渠道设置 | 登录、用户数据隔离、管理后台，以及由部署者配置的模型渠道和用户密钥管理 |

上述描述指源码中包含的界面与机制。**仓库默认没有 AI 渠道，不附带原站供应商、密钥或专用适配代码。** 实际生成能力需要部署者接入自己的服务：文本可使用内置的 Chat Completions 协议；图片、视频、音频和草稿服务需要相应的服务器适配器，详见 [API 接入契约](docs/api-boundary.md)。

## 典型使用流程

接好所需服务后，可以围绕一条视频内容组织以下流程，并按实际创作需要选择阶段：

**输入选题或已有剧本 → 整理和优化文案 → 设计分镜与提示词 → 生成配音、图片及视频 → 查看结果并下载素材或对接草稿导出。**

每个阶段的实际效果取决于输入内容、所接模型及适配器。这里提供工作流系统与代码参考，不承诺一键生成可直接发布的完整成片。

## 技术组成

- 前端：Next.js 15 / React 19，提供工作流、素材和创作界面。
- 后端：Node.js API，处理身份验证、数据保存与模型调用。
- 后台任务：Worker 执行生成和分析等耗时任务。
- 存储：本机预览采用 JSON；源码提供 PostgreSQL 存储与迁移实现，多进程部署尚未实机验收。

## 本地预览

需要 Node.js 24 或更新版本。此路径不需要 Docker，不访问原站点。

```sh
npm ci
npm --prefix server ci
npm run local:setup
npm run build
npm run local:start
```

访问 http://127.0.0.1:13000 。管理员邮箱为 `admin@example.invalid`，密码从本机 `.local/server.env` 读取；该文件不提交。API 监听 18787。首次登录时创建管理员。

本地运行器强制真实登录验证，将 API 与五类 Worker 放在同一进程，以避免 JSON 开发存储的跨进程缓存问题。该模式仅用于本机验证；正式多人部署应使用 PostgreSQL，相关独立部署验收尚未完成。

没有配置模型凭证时，不能完成真实生成。请勿使用生产数据库、生产存储或真实客户数据测试。
